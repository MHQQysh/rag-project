# 电商分析子项目设计

用户已批准在现有仓库新增并列子项目，保留 Python 完整版并增加 GitHub Pages 网页版；允许需要时部署后端。

本次采用无需后台服务器的模拟数据网页版。仓库新增 db-gpt-commerce；现有两个项目保持独立。web 使用原生模块、sql.js WebAssembly、Worker 隔离查询、JavaScript 独立明细核验和 BigInt 分数贡献分解。浏览器直接向 DeepSeek 官方接口发送用户主动输入的 Key；不持久化 Key、不读本机环境密钥、不将 Key 写入证据。使用固定 schema 和月份地区参数，模型最多修复一次 SQL，失败不伪装成功。

数据由 Python 生成器重新生成公开模拟库，提供同源 WASM 和数据库资源。查询仅限单条读取，Worker 超时终止，结果必须与独立原始行核验一致。JS 版本不宣称执行官方 Python AWEL；源码与文档明确区分两个运行环境。界面包含设置、分析、贡献图、渠道明细、SQL 与步骤、证据下载、代码逻辑说明。

GitHub Actions 只发布 web 与讲解静态文件，不发布 Python 环境、日志、.env 或本地运行文件。上线前验证已知数值、跨月退款、错误 SQL、超时、取消、无 Key、API 错误、子路径部署和产物密钥扫描。真实模型验证只有在用户通过网页输入 Key 后才能完成，不把旧密钥注入页面。

保留 Windows 官方版安装启动脚本，增加后端部署说明：本机先验证；若需要共享完整 DB-GPT，使用独立 Linux 主机/容器，数据库置于持久化卷，模型密钥置于服务器环境变量，认证与 HTTPS 由网关提供；这部分与 Pages 分开部署，不宣称本次已上线完整后端。
