# 网页版验证记录

日期：2026-09-29。此记录对应新增浏览器移植版，旧 Python 官方版验证见 VALIDATION.md。

- Node 自动化测试 10 项通过：四组地区/月度结果逐项与 Python Fraction 结果一致，包含总指标、四项贡献、六种顺序和填补说明。
- 覆盖重复渠道、错误金额、非法类型、缺行、跨月成功退款、失败退款排除、整月零订单、单渠道零订单等场景。
- 模型模块使用模拟 HTTP 返回验证固定官方接口、密钥不进入返回记录、缺 Key、401/402/429/500 和无效 JSON；这些不是模型生成准确率测试。
- 浏览器中从 `/db-gpt-commerce/` 子路径实际运行基准：净收入 141,000 元，上期 240,000 元；四项贡献与 Python 一致，SQL 核验成功。
- 浏览器无 Key 时展开输入框并提示；使用明确无效的测试值实际请求 DeepSeek，返回密钥无效错误，没有保留旧成功报告或伪造模型结果。
- 页面使用 textContent 显示 SQL 和错误，不将模型文本插入 HTML；密钥不使用 localStorage/sessionStorage，不进入 Worker 或下载证据。
- 公开数据从生成器在临时目录重新生成，没有复制本机运行数据库。

尚未使用真实付费 Key 验证网页版成功生成链路；用户在页面输入自己的 Key 后可运行。没有把历史本地 DeepSeek 成功记录当作本版成功证据。对模型调用存在延迟、额度、限流和网络条件的依赖。

构建：进入 web 执行 `npm ci`、`npm run build`。产物只包含静态 app、同源 sql.js 与许可、公开样本和讲解文档。
