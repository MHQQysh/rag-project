UNDER THE HOOD

整个项目，其实只有这几层

① 窗口与调度

这里收集地区和月份，展示运行进度。本地完整版由官方 DB-GPT Agent 选择工具；网页版直接运行专用流程。

app.mjs / official_integration.py
② 模型写查询

DeepSeek 接收表结构与指标规则，返回候选 SQL。模型不直接计算报告中的金额。

model.mjs / workflow.py
③ 程序核对数据

SQL 在浏览器 SQLite 中运行，再用逐条订单和退款计算核对。未通过则最多修复一次，仍失败就停止。

query-worker.js / query.py
④ 程序计算贡献

按六种替换顺序求平均边际变化，用精确分数确保贡献加总等于净收入变化，最后生成展示与证据。

core.mjs / analysis.py

这个网页无需自建后端。它是受限场景的浏览器移植版，不运行 Python AWEL，也不接入企业私有数据。完整官方版与服务器部署说明见项目 README。
